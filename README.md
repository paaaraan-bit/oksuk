# 저승 알바천재 노수오

장편소설 원고와 교정 작업 공간입니다.

## 이렇게 말씀하시면 됩니다

- "3장 교정해 줘" → 맞춤법·띄어쓰기·비문을 고치고, 고친 곳을 표로 보여 드립니다.
- "3장 문장도 좀 다듬어 줘" → 문장을 다듬는 제안을 따로 보여 드립니다(원문은 그대로 둡니다).
- "좋아, 확정" 또는 "저장해 줘" → 고친 원고를 저장합니다. 다음 대화에서도 그대로 이어집니다.
- "지금 어디까지 했지?" → 진행 현황을 알려 드립니다.
- "전체 원고 파일로 줘" → 원고 전체를 한 파일로 만들어 드립니다.

한 대화에서 한 장씩 하시면 비용이 가장 적게 듭니다.
